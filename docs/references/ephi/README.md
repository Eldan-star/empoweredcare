# EPHI reference manuals

Public EPHI guidelines and manuals, converted to Markdown so they can be searched and
quoted.

| File | Document |
|---|---|
| `PHEM_Guideline_Second_Edition_December_2022-5_compressed.md` | PHEM Guideline for Ethiopia, 2nd edition, Dec 2022. **The main authority** for case definitions, thresholds and reporting |
| `EPHI_cPHEM_EWISMD_CEBS_Implementation_Manual_2021.md` | Community and Event Based Surveillance Implementation Manual, Sep 2021 |
| `National Public Health Emergency Operations Center Guideline-2022.md` | National PHEOC Handbook, Apr 2022 |
| `ETHIOPIAN pUBLIC HEALTH INSTITUTE-2023.md` | PHEM at Healthcare Facilities: Participant Manual, Apr 2023 |

- Printed page numbers appear as lines in the text. Cite as document, table or annex, and
  page.
- Case definitions, thresholds and trigger types used in the code are checked against these
  documents. The comparison is in `docs/EPHI_ALIGNMENT.md`.
- The conversions are search aids. Where a quote matters, check it against the original PDF.
  Adding the PDFs here is recommended.
