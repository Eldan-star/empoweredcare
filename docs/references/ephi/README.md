# EPHI reference manuals

Public EPHI guidelines and manuals: PHEM, measles, community event-based surveillance
trigger lists, and others.

- Put the original PDFs here, unchanged, and name each file after the document's title and
  year.
- Case definitions, thresholds and trigger types used in the code are checked against these
  documents and cited by file name and page.
- A plain-text conversion of each PDF sits next to it so that it can be searched and
  quoted. Conversions are tools for searching; the PDF is the authority.
